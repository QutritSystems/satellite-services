# SatMarket 競品分析報告

## 各競品分析

### AWS Ground Station
按分鐘計費的 pay-as-you-go，區分窄頻（<40 MHz）和寬頻（≥40 MHz）。
只服務「衛星通訊下行」的地面站功能，不涵蓋影像、雷達、氣象等多樣服務。高度依賴 AWS 生態，非 AWS 用戶上手門檻高，沒有仲介衛星時段的市集概念。

### Leaf Space
按分鐘計費、pay-as-you-go，無最低承諾。服務中小型衛星星座、CubeSat 業者。
純 B2B 地面站服務，買方必須自己有衛星，不提供衛星服務時段給無衛星的企業。

### Infostellar（StellarStation）
Pay-as-you-go，以積分購買，支援閒置地面站時段共享。最接近市集模式，但焦點僅限「地面站通訊時段」，未延伸至衛星服務成果（影像、雷達數據等）。

### Atlas Space Operations（Freedom® 平台）
訂閱制，客製化報價，無公開定價。完全是企業級產品，無自助式線上交易，銷售流程長。2025 年被 York Space Systems 收購後定位更偏向垂直整合。

### HawkEye 360
衛星 RF 情報分析公司，非市集平台。主要服務國防和情報機構。未來反而可能是 SatMarket 的潛在供應商。

## 市場缺口總結

| 缺口 | 現況 |
|------|------|
| 即時自助交易 | 所有競品均無公開定價或線上即時預訂，都需業務接洽 |
| 買方無需擁有衛星 | 現有平台全部服務衛星營運商，沒有平台讓企業直接買衛星服務時段 |
| 多類型服務整合 | 現有平台聚焦地面站通訊，無法跨越影像、氣象、雷達於單一市集 |
| 短期彈性購買 | 沒有平台提供小時級衛星服務時段，最低採購門檻普遍以月為單位 |
| 透明公開定價 | 市場幾乎無公開報價，阻礙中小企業進入 |

## SatMarket 差異化建議

**核心定位：衛星服務的 Airbnb 終端市集——服務買方，而非服務衛星運營商**

1. **公開即時定價 + 線上完成交易** — 全市場唯一能讓買家直接看到價格、選時段、付款的平台
2. **最低購買單位：小時/次，非月份** — 降低試用門檻
3. **多類型衛星服務整合於單一市集** — 影像、通訊、氣象、雷達同一平台比較預訂
4. **供應商自助上架** — 讓中小型衛星營運商能自主上架

**早期建議聚焦的垂直市場（擇一驗證）：**
- 農業精準作業（需要定期特定區域影像，預算有限）
- 海事監控（有付費意願、資料需求週期清晰）
- 大學/研究機構（科研經費、彈性需求、對新平台接受度高）

## 10% 抽成建議

| 階段 | 建議 |
|------|------|
| 冷啟動期 | 供應商收 0%，只向買家收 5-10%，快速擴充供給側 |
| 成熟期 | 供應商 5% + 買方 8-10%，有效抽成約 13-15%（接近 Airbnb） |
| 大額訂單 | 超過 $50,000 的部分抽成降至 5%，避免繞平台直接交易 |

不建議月訂閱制，市集的核心競爭力是「無承諾」。
